## 🎯 3 PASSOS PARA COMEÇAR

### **1. PERSONALIZAR (5 minutos)**

Abra o arquivo `.env` e edite:

```env
CONSULTORIO_NOME="Clínica da Dra. [Nome dela]"
DENTISTA_NOME="Dra. [Nome Completo]"
CONSULTORIO_TELEFONE="55[DDD][Celular]"
```

---

### **2. INICIAR (2 minutos)**

Dê duplo clique em: `iniciar-bot.bat`

Ou pelo terminal:
```bash
npm start
```

---

### **3. CONECTAR WHATSAPP (1 minuto)**

1. QR Code aparece no terminal
2. WhatsApp → Aparelhos conectados
3. Escanear código

✅ **PRONTO! Bot online!**
